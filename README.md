# Klimperhelden – Downloads

Klimperhelden ist ein Lernspiel für Kinder (6–12 Jahre): Klavier spielen lernen mit einem MIDI-Keyboard oder Klavier. Mit Weltenkarte, Heldenstunden, Liedern, Notenmonstern, Klavierbuch für Fortgeschrittene und echtem Notenblatt.

## Windows installieren

1. Unter **[Releases](https://github.com/thecrafti87/PianoPlay-releases/releases/latest)** die Datei `Klimperhelden-<Version>-Setup.exe` herunterladen.
2. Starten. Windows warnt beim ersten Mal, weil das Programm nicht signiert ist: **„Weitere Informationen“ → „Trotzdem ausführen“**.
3. Fertig. Klimperhelden sucht danach selbst nach neuen Versionen und bietet „Jetzt neu starten“ an.

Ohne Installation geht `Klimperhelden-<Version>-portable.exe`, die aktualisiert sich aber nicht selbst.

## Keyboard

MIDI-Keyboard per USB anstecken (z. B. ein Steuer-Keyboard oder ein Digitalpiano). Klimperhelden erkennt es von selbst. Immer nur **ein** Klimperhelden-Fenster öffnen: Windows gibt ein Keyboard nur an ein Programm gleichzeitig.

## Quellen

Flügel-Aufnahmen: „Salamander Grand Piano“ von Alexander Holm, Lizenz CC BY 3.0. Alle Lieder sind gemeinfrei, in eigenen Bearbeitungen. Die vollständigen Lizenzen stehen im Spiel unter Einstellungen → Sprache & Info → Lizenzen.
