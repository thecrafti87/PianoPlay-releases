Keyboard anschließen

Das Keyboard per USB anschließen (am iPad und iPhone mit einem USB-C- oder Lightning-Adapter). Das Spiel erkennt es von selbst. Ein Keyboard ohne Kabel geht mit der Einstellung „Keyboard ohne Kabel“ (Mikrofon).

Kauf wiederherstellen

Einstellungen → Sprache & Info → Für Eltern → Aufgabe lösen → Vollversion → „Käufe wiederherstellen“.

Spielstand sichern

Auf iPad und iPhone sichert das Spiel den Spielstand automatisch in Ihrer iCloud. Als Datei geht es auch: Für Eltern → Sicherung.

Connecting a keyboard

Connect the keyboard via USB (on iPad and iPhone with a USB-C or Lightning adapter). The game detects it automatically. A keyboard without a cable can be used with the setting “keyboard without cable” (microphone).

Restoring a purchase

Settings → Language & info → For parents → solve the task → Full version → “Restore purchases”.

Backing up progress

On iPad and iPhone, progress is backed up to your iCloud automatically. You can also save it as a file: For parents → Backup.
